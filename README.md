# Cat vs Dog Desktop App

Десктопное приложение для классификации изображений
(кот / собака) с использованием Flet и TensorFlow.

---

## Возможности

- загрузка изображений JPG/PNG;
- отображение изображения;
- классификация кот/собака;
- отображение вероятности;
- обработка ошибок.
